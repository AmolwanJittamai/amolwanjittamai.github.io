# Amolwan Jittamai — Academic Bio Website

A static, responsive academic bio and digital CV website designed for free hosting on GitHub Pages.

## Files

- `index.html` — the complete website (HTML + CSS in one file)
- `amolwan-jittamai.jpg` — headshot used in the hero section
- `Amolwan-Jittamai-CV.docx` — downloadable full CV
- `favicon.svg` — browser-tab icon

## Publish with GitHub Pages

1. Sign into GitHub.
2. Create a **public** repository named `YOUR-USERNAME.github.io`.
3. Upload all four site files from this folder to the repository root.
4. Commit the files to the `main` branch.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select `main` and `/(root)`, then click **Save**.
8. Your site will be available at `https://YOUR-USERNAME.github.io/` after GitHub finishes publishing it.

## Updating the website later

Edit `index.html` in GitHub or replace it with an updated copy, then commit the change. GitHub Pages will republish automatically.

## Customize

The site intentionally has no LinkedIn or GitHub profile buttons because those URLs were not included in the supplied CV. If you want them, add the links to the hero or contact section in `index.html`.
